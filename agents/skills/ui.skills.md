# UI Agent Skills

## Objective

Implement the storefront experience defined by the UI agent.

## Execution Steps

1. Define Tailwind theme tokens for the furniture store palette, typography, spacing, and border treatments.
2. Build shared layout primitives: header, footer, section wrapper, buttons, and empty states.
3. Build commerce primitives: hero banner, product card, product grid, catalog filters, product gallery, and product info panel.
4. Implement the home page with hero, featured products, trust content, and WhatsApp CTA band.
5. Implement the catalog page with filter UI, sort controls, and responsive product grid.
6. Implement the product detail page with gallery, summary, inquiry CTA, and supporting product information.
7. Implement About and Contact pages following the same visual system.
8. Ensure responsive behavior for navigation, filters, media blocks, and CTA placement.
9. Add loading, empty, and error states that match the minimal visual language.
10. Verify color contrast, keyboard navigation, and semantic headings.

## Validation Checklist

- Product images remain dominant at all breakpoints.
- Accent colors are used sparingly and consistently.
- Catalog filters are usable on both desktop and mobile.
- The WhatsApp CTA is visible in high-intent areas without competing with checkout.
- Typography scale and spacing remain consistent across all storefront pages.
